# Wiki Drafts

Store unpublished wiki article drafts here.

Rules:

- Keep drafts in markdown format so they are easy to move into the public wiki later.
- This folder is for source control and backup across machines.
- Do not import anything from this folder into the public app.
- When an article is ready to publish, move it into `src/data/public/wiki/`.

Suggested workflow:

1. Draft the article in the local editor at `/wiki/editor`.
2. Download or copy the generated markdown.
3. Save the file in `drafts/wiki/` while it is still in progress.
4. Commit and push drafts if you want them backed up across devices.
5. Move the finished file into `src/data/public/wiki/` when ready to publish.
